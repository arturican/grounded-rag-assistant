# `a85a500` - embeddings provider interface

## Что появилось

Введён интерфейс провайдера эмбеддингов и тесты, которые работают без внешней модели.

## Как это работает

Вместо прямых вызовов к конкретной embedding-библиотеке приложение обращается к абстракции. Это позволяет использовать фейковую реализацию в тестах и реальную - позже, когда придёт время подключать настоящую модель.

## Зачем это нужно

Это важный архитектурный шов. Он удерживает проект тестируемым и не даёт доменной логике зависеть от тяжёлых внешних компонентов слишком рано.
