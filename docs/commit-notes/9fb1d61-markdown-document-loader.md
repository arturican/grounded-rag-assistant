# `9fb1d61` - markdown document loader

## Что появилось

Поддержка загрузки `.md`-файлов добавлена в тот же слой `loaders.py`, а тесты расширены под markdown-сценарии.

## Как это работает

Markdown пока используется как текстовый источник без сложного структурного парсинга. Файл читается как текст, после чего содержимое можно нормализовать, разбивать на чанки и индексировать так же, как `.txt`.

## Зачем это нужно

Для учебной и рабочей документации markdown встречается очень часто. Поддержка `.md` делает проект полезнее на реальном наборе локальных документов практически без усложнения архитектуры.
