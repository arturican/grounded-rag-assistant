# 2026-04-14-cli-non-paged-source-rendering-regression.md

В этом коммите добавлена регрессионная проверка для CLI, гарантирующая правильный рендеринг источников, не имеющих метаданных о страницах.

### Что изменилось

1.  **Тесты**:
    - В `backend/tests/test_cli.py` добавлен метод `test_run_cli_renders_non_paged_sources_without_page_suffix_regression`.
    - Тест проверяет, что при обработке обычных текстовых файлов (без страниц) в блоке `Sources:` отсутствует суффикс `page None`.

### Как это работает

- При вызове команды `ask` в CLI, система использует функцию `format_sources`.
- Для источников с `page=None` функция возвращает строку вида `path (chunk_id)`.
- Тест подтверждает, что в итоговом выводе CLI мы видим именно такой формат, и в нём нет лишних данных о страницах.

### Зачем это нужно

Это важный шаг в Phase 9 (Evaluation and quality), направленный на стабилизацию вывода CLI. Без этой проверки будущие изменения в логике форматирования могли бы случайно вернуть `page None` или другой некорректный формат, что ухудшило бы читаемость ответов для пользователя.

### Как запустить проверку

```bash
export PYTHONPATH=$PYTHONPATH:.
python3 -m unittest backend.tests.test_cli -v
```
