# `7d68951` - in-memory retrieval store

## Что появилось

Добавлено локальное in-memory хранилище эмбеддингов и чанков с поиском `top_k`, плюс тесты на ранжирование.

## Как это работает

При добавлении чанков хранилище получает эмбеддинги через провайдер, сохраняет их рядом с метаданными и затем по запросу вычисляет близость запроса к индексированным чанкам. На выходе возвращаются `RetrievedChunk` с `score`.

## Зачем это нужно

С этого коммита в проекте появляется настоящее retrieval-поведение, пусть пока и без FAISS. Это уже не просто подготовка данных, а поиск полезного контекста по вопросу пользователя.
