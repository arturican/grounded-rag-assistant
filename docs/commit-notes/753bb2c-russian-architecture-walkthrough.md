# `753bb2c` - Russian architecture walkthrough

## Что появилось

В репозитории появился цельный русскоязычный обзор архитектуры проекта: [docs/ARCHITECTURE_RU.md](/home/art/project/grounded-rag-assistant/docs/ARCHITECTURE_RU.md). В [README.md](/home/art/project/grounded-rag-assistant/README.md) также добавили ссылку на этот файл в карте репозитория.

## Как это работает

Если `docs/commit-notes/` объясняет проект по маленьким историческим шагам, то `ARCHITECTURE_RU.md` собирает текущее состояние системы в одну непрерывную картину. В нём описаны основные сценарии `index` и `ask`, назначение слоёв ingestion, retrieval, answering, CLI и API, а также путь данных через систему.

## Зачем это нужно

История по коммитам полезна для обучения, но в какой-то момент читателю нужно быстро понять весь проект целиком. Этот коммит закрывает именно эту потребность: теперь в репозитории есть документ, по которому можно войти в архитектуру без необходимости сначала перечитывать весь git log.
