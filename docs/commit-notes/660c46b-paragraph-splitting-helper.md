# `660c46b` - paragraph splitting helper

## Что появилось

Добавлен шаг разбиения нормализованного текста по абзацам и обновлены тесты chunking-слоя.

## Как это работает

После очистки пробелов текст делится на смысловые блоки по пустым строкам. Это более естественная единица, чем фиксированное число символов: абзац часто уже содержит локально завершённую мысль.

## Зачем это нужно

Для RAG важно не только найти похожий текст, но и сохранить читаемый контекст. Разбиение по абзацам обычно даёт более качественные чанки для поиска и последующего ответа.
