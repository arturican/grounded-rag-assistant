# `3a938d2` - init project

## Что появилось

Создан каркас репозитория: `README.md`, `AGENTS.md`, `docs/PROJECT_BRIEF.md`, `docs/ROADMAP.md`, `docs/NEXT_STEP.md`, базовая структура `backend/app` и `backend/tests`.

## Как это работает

Этот коммит не добавляет бизнес-логику RAG, а задаёт правила игры. Документы в `docs/` фиксируют цель проекта, этапы разработки и следующий маленький шаг. `AGENTS.md` объясняет, как агентам и людям вносить изменения безопасно и последовательно.

## Зачем это нужно

Без такого основания проект быстро превращается в набор несвязанных экспериментов. Этот коммит делает репозиторий продолжабельным: новый человек или агент может понять цель, ограничения и порядок работы без чтения всей переписки.
