# `ffd8742` - local CLI vertical slice

## Что появилось

Собран первый сквозной CLI-срез: команды `index` и `ask`, локальное сохранение индекса и тесты CLI.

## Как это работает

Команда `index` проходит по директории, загружает поддерживаемые документы, строит чанки, индексирует их и сохраняет результат. Команда `ask` загружает сохранённый индекс, ищет релевантные чанки и печатает grounded-ответ вместе с источниками.

## Зачем это нужно

Это момент, когда проект из набора отдельных модулей становится реально запускаемым продуктом. Даже без UI и сложного API уже можно показать полный сценарий: проиндексировать документы и задать вопрос.
