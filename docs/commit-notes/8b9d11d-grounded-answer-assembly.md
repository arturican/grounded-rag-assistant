# `8b9d11d` - grounded answer assembly

## Что появилось

Добавлен детерминированный слой ответа: `build_grounded_answer`, форматирование источников и тесты на честный отказ при нехватке контекста.

## Как это работает

Функция берёт уже найденные `RetrievedChunk`, проверяет минимальный порог качества и, если контекст достаточный, собирает ответ только из выбранных чанков. Если контекст слабый, возвращается явное сообщение о невозможности ответить по найденному материалу.

## Зачем это нужно

Это центральное правило всего проекта: не фантазировать, а отвечать только из найденных фрагментов. Именно здесь идея grounded RAG закрепляется в коде.
