# `43d2c32` - sliding-window text chunking

## Что появилось

Добавлена оконная логика chunking для длинных абзацев, обновлены тесты и README с командами проверки.

## Как это работает

Если абзац слишком длинный и не помещается в один чанк, он режется на последовательные окна с перекрытием. Перекрытие нужно, чтобы информация на границе чанков не терялась полностью при поиске.

## Зачем это нужно

Реальные документы часто содержат длинные фрагменты без удобных естественных границ. Sliding window закрывает этот случай и делает chunker пригодным не только для аккуратно структурированных текстов.
