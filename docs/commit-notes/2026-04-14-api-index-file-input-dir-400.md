# Commit: guard index endpoint for file input_dir

## Цель исправления

Убрать тихое и вводящее в заблуждение поведение `/index`, когда `input_dir` существует, но указывает не на директорию, а на обычный файл.

## Как была обнаружена проблема

Проблема пришла из внешнего аудита, после чего была перепроверена по текущему коду `backend/app/api.py`: endpoint проверял путь недостаточно строго перед запуском индексации.

## Почему это реальная проблема

Если клиент по ошибке отправляет путь к файлу вместо директории, API не должен вести себя как будто вход валиден. Без явной проверки ошибка пользователя превращается в неочевидное поведение глубже по стеку.

## Что изменено

- В `backend/app/api.py` добавлена ранняя проверка, что существующий `input_dir` обязан быть директорией.
- Для этого случая API теперь возвращает `HTTP 400` с детерминированным `detail`.
- В `backend/tests/test_api.py` добавлен ровно один узкий regression test на scenario "существующий файл вместо директории".
- В `docs/NEXT_STEP.md` зафиксирован следующий минимальный шаг после этого исправления.

## Как работает исправление

`/index` теперь прерывает обработку до индексации, если `input_dir` уже существует, но `Path(...).is_dir()` возвращает `False`. Клиент получает ответ `400` с сообщением `input_dir is not a directory: ...`.

## Почему решение сделано именно так

Это самый маленький безопасный шаг: успешный путь `/index` не меняется, область правки ограничена API-валидацией, а новый тест проверяет ровно один failure mode.

- `python3 -m unittest backend/tests/test_api.py -v`
- `python3 -m py_compile backend/app/api.py backend/tests/test_api.py`

## Результат проверки

- `python3 -m unittest backend/tests/test_api.py -v` не смог выполниться в текущем окружении, потому что локальный `python3` не содержит установленный пакет `fastapi` (`ModuleNotFoundError` при импорте `fastapi.testclient`).
- Синтаксическая проверка `python3 -m py_compile backend/app/api.py backend/tests/test_api.py` прошла успешно.

## Ограничения

- Этот коммит не исправляет failure mode для PDF без extractor.
- Более широкий API regression run не выполнялся, потому что окружение сейчас не содержит нужных runtime/test зависимостей.

## Следующий логичный маленький шаг
