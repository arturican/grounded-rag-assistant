# Заметки о рецензировании (Review Notes)

В этом каталоге хранятся результаты проверки изменений, внесённых Codex.

## Зачем это нужно
- Чтобы видеть историю проверок и принятых решений.
- Чтобы Codex мог учиться на ошибках, найденных во время ревью.
- Чтобы сохранить историю "тонких моментов", не попавших в код.

## Как хранить заметки
1. Создавай новый файл на каждый проверенный шаг.
2. Используй имя в формате `YYYY-MM-DD-<step-name>.md`.
3. Копируй содержимое из `TEMPLATE.md`.
4. Заполни все разделы шаблона.

## Когда создавать заметку
- Сразу после того, как Codex выполнил задачу из `docs/NEXT_STEP.md`.
- До того, как Codex перешёл к следующей задаче.
