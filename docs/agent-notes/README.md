# Agent Notes

Каталог для коротких рабочих заметок агента между шагами.

## Когда использовать

- есть риск забыть контекст до следующего маленького commit;
- найден blocker, который нельзя закрыть в текущем шаге;
- нужно зафиксировать наблюдение для следующего агента.

## Что хранить

- только факты: проблема, воспроизведение, гипотеза, следующий безопасный шаг;
- ссылки на конкретные файлы/команды;
- нерешенные вопросы, если без них нельзя продолжать.

## Что не хранить

- длинные дубли README/ARCHITECTURE;
- неподтвержденные утверждения;
- секреты и локальные credentials.

## Формат имени файла

`YYYY-MM-DD-<short-topic>.md`

Пример: `2026-04-14-frontend-ask-error-handling.md`
