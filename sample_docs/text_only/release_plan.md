# Project Atlas Pilot Release Plan

Project Atlas will begin its pilot launch on 2026-05-20.
The first pilot customers are Harbor Health and Pine Market.

Launch command coverage will run on weekdays from 08:00 to 18:00 UTC.
Rollback decisions for the pilot are owned by Mira Chen.

The primary success metric is a 20 percent reduction in ticket triage time by the end of June 2026.
Any Friday launch change after 15:00 UTC requires director approval.
